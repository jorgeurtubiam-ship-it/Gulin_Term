# Navegador Web Agéntico

GuLiN Terminal no es solo una interfaz de línea de comandos; incluye un widget de navegador web completamente funcional que la IA puede controlar de forma autónoma.

## Capacidades
La IA usa las siguientes herramientas internas para interactuar con páginas web sin salir de tu terminal:
- `web_navigate`: Ordena al widget del navegador abrir una URL específica.
- `web_read_page`: Extrae el contenido de texto del widget del navegador activo actualmente para su análisis o resumen.
- `web_click`: Identifica y hace clic en elementos de la página (como enlaces o botones).
- `web_type`: Simula entradas de teclado para rellenar formularios o cajas de búsqueda.

## Casos de Uso
- Leer la documentación de una API directamente en la ventana de contexto.
- Buscar en StackOverflow soluciones a errores que aparecen en la consola.
- Interactuar con dashboards web internos o paneles de administración.
