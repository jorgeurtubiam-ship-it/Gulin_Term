# Key Bindings & Customization

GuLiN Terminal is built for power users. This means you can keep your hands on the keyboard for almost any action.

## Default Key Bindings
GuLiN supports standard Unix/Linux terminal shortcuts along with application-specific commands:
- **`Ctrl+T` / `Cmd+T`**: Open a new tab.
- **`Ctrl+W` / `Cmd+W`**: Close current tab/widget.
- **`Ctrl+Shift+F`**: Open workspace semantic search (Auto-RAG).
- **`Ctrl+Space`**: Toggle AI Assistant popup.

## UI Customization
The layout of GuLiN Terminal is highly modular. You can drag and drop widgets (Terminals, AI Chats, Previews, Web Browsers) to organize your workspace. Layouts can be split horizontally or vertically, and are automatically saved per session.
