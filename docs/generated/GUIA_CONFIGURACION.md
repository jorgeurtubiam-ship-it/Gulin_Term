# GUÍA CONFIGURACIÓN - GuLiN

## 1. Variables de Entorno
- `WCLOUD_ENDPOINT`: Endpoint principal de la nube.
- `WCLOUD_WS_ENDPOINT`: Endpoint de WebSockets.

## 2. Configuración de Providers
Configurados en `gulin.config.json` o mediante variables de entorno según el provider (OpenAI, Anthropic, Ollama).
