## 🌐 ¿Qué es GuLiN Terminal?

**GuLiN** va mucho más allá de un terminal convencional o un simple cliente de chat. Es una **plataforma agéntica integral** que fusiona:


## 🚀 Los 6 Pilares de GuLiN

### 1. 🧠 Orquestador Multi-IA Universal (Conmutación en Caliente)
* **Compatibilidad Total:** Conéctate con **Max 3**, **Claude 3.5 Sonnet**, **Gemini 2.0 Pro/Flash**, **OpenAI GPT-4o**, **DeepSeek R1/V3** y modelos locales **100% privados y sin costo con Ollama**.
* **Hot-Swap sin pérdida de contexto:** Cambia de motor sobre la marcha según la complejidad del requerimiento.
* **Gulin Brain (Auto-RAG):** Memoria semántica persistente a largo plazo que indexa el código de tus proyectos, servidores, logs e historial para ofrecer respuestas ultra-precisas.

---

### 2. 🗄️ DB Maestro: Gestión Universal de Bases de Datos & Big Data
* **Soporte Multi-Motor Nativo:** **PostgreSQL, MySQL, MariaDB, SQLite, MongoDB, Redis, Cassandra, Oracle (con Standby/Data Guard), DB2, SAP HANA, Sybase y Dremio (Data Lakehouse / Parquet / Apache Iceberg)**.
* **DBA Autónomo en Lenguaje Natural:**
  * Generación y ejecución de consultas SQL/NoSQL complejas.
  * Análisis proactivo de rendimiento, optimización de queries lentas, auditoría de tablespaces e índices.
  * Instalación y configuración desatendida de bases de datos y réplicas de alta disponibilidad en minutos.
* **Visual Data Explorer:** Inspección visual de tablas, relaciones DDL y monitores gráficos de métricas en tiempo real.

---

### 3. ☁️ Infraestructura, Multi-Host SSH & Cloud DevOps
* **Gestor de Servidores & Flotas SSH:** Controla decenas de servidores remotos con auto-conexión y diagnóstico proactivo.
* **Contenedores & Kubernetes:** Despliegue, inspección de pods, depuración de logs en vivo y reinicio inteligente de servicios en Docker y K8s.
* **Mapa Topológico de Infraestructura (Service Map):** Descubrimiento visual en tiempo real de nodos, microservicios, bases de datos, flujos de red y latencias.
* **Bóveda Segura de Secretos (API Manager):** Gestión centralizada y cifrada de credenciales cloud (AWS, Azure, GCP) y endpoints de integración.

---

### 4. 🌐 Navegador Autónomo Agéntico (Agentic Web Browser)
* Un navegador integrado que el agente opera de forma 100% autónoma:
  * Navega la web, interactúa con el DOM, completa formularios y resuelve flujos web.
  * Extrae documentación técnica, compara precios o valida estados de APIs externas en tiempo real.

---

### 5. 📑 Suite DocGen Ejecutiva & Business Intelligence
* **Exportación Directa a Suite Ofimática:** Transforma cualquier salida de terminal, diagnóstico de servidor o consulta de datos en:
  * **Presentaciones PowerPoint (`.pptx`)** con diapositivas ejecutivas y diseño moderno.
  * **Reportes Word (`.docx`)** formateados profesionalmente listos para entregar a gerencia.
  * **Planillas Excel (`.xlsx`)** con tablas estructuradas, fórmulas y gráficos dinámicos.
* **Visual BI Dashboards:** Gráficos interactivos de radar, líneas, barras y diagramas de flujo integrados en el espacio de trabajo.

---

### 6. 💻 Terminal Split de Alto Rendimiento & Tsunami SDK
* **Motor Híbrido PTY:** Terminal de baja latencia escrito en Go con emulación completa de shell (zsh, bash, fish, PowerShell).
* **Workspace Dividido:** Terminal interactivo a la derecha + Chat IA con razonamiento aislado (*chain-of-thought*) a la izquierda con botones de ejecución en 1 clic.
* **Control por Voz Manos Libres:** Activa y comanda el terminal mediante voz con detección de *wake-word*.
* **Tsunami SDK:** Framework para crear micro-aplicaciones personalizadas de terminal usando Go y Virtual DOM.

## ⚡ Instalación en 1 Línea

### 📦 Producción (Compilación Automática del Instalador para tu OS)

```bash
git clone https://github.com/jorgeurtubiam-ship-it/Gulin_ia.git
cd Gulin_ia
chmod +x install.sh
./install.sh
```

### 🛠️ Modo Desarrollo (Hot-Reload)

```bash
npm install && task build
task dev
```
