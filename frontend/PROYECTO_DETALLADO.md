# Mapa Detallado del Proyecto

Este documento mapea cada archivo del proyecto con su propósito funcional.

## Directorio: /types
- `jsx.d.ts`: Definiciones de tipos para JSX.
- `gulinevent.d.ts`: Definiciones de tipos para eventos del sistema GuLiN.
- `media.d.ts`: Tipos relacionados con elementos multimedia.
- `vite-env.d.ts`: Definiciones de entorno para Vite.
- `custom.d.ts`: Definiciones de tipos personalizados.
- `gotypes.d.ts`: Tipos para la integración con Go.

## Directorio: /app
- `app.tsx`: Componente raíz y punto de entrada de la aplicación.
- `reset.scss`: Normalización y reseteo de estilos CSS.

## Directorio: /app/workspace
- `widgets.tsx`: Gestión de la renderización de widgets.
- `widgetfilter.ts`: Lógica de filtrado de widgets.
- `widgetfilter.test.ts`: Tests para el filtrado de widgets.
- `workspace.tsx`: Componente principal del espacio de trabajo.
- `workspace-layout-model.ts`: Modelo de datos para la disposición del layout.
